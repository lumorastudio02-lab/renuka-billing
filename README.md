# Renuka Billing & Paramedical Fee Dashboard

Comprehensive Fee Collection, Student Management, and Financial Tracking System for Renuka Paramedical Institute.

## Architecture

- **Frontend**: React + Vite + TanStack Router + TailwindCSS (located in `frontend/`)
- **Backend**: Node.js + Express + MongoDB / PostgreSQL (located in `backend/`)
- **Scripts**: Unified development runner in `scripts/dev.js`

## Quick Start

### Run Development Environment
```bash
npm run dev
```

### Backend
```bash
cd backend
npm run dev
```

### Frontend
```bash
cd frontend
npm run dev
```
